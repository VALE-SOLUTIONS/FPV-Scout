# NM-CYD-C5 scanner port

FPV Scout boots directly into scanning with the board's ST7789 LCD and XPT2046 touch panel. The former ESPsoup/C5VRX app switch is removed from this build.

See the [scanner guide](../docs/scanner.md) for controls, wiring, build and installation, and the [validation record](../docs/validation.md) for what has actually been tested.
